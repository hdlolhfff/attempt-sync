# Attempt Sync
Sync Attempt Playback 1.5.7 ghost recordings through your private GitHub repository on Windows, macOS, and iOS/iPadOS.

Configure Repository, Branch and GitHub Token in this mod's settings. Tap Sync on the main menu, then optionally enable Sync at Main Menu.

A fine-grained token needs Contents read/write access to your replay repository. Tokens are stored locally in plain text. Backups are kept before imports. Sync combines recordings and does not propagate deletions.
