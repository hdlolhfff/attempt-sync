Live progress now appears in the same bottom notification as "Attempt Sync finished".

- One persistent banner updates in place while connecting, comparing, awaiting approval, uploading, retrying and applying files.
- Uploads show file N / total and completed-file percentage without tapping Sync.
- Completion updates that banner with the level count, then dismisses it after four seconds.
- Preserves one Sync All confirmation, merged playback histories and backups.

The public build is token-free. SideStore/JIT-less: fully close GD, import the exact **local.attempt_sync.geode** file using **Files → Share → Geode / Geode Launcher**, wait for import confirmation, then use launcher **Settings → Force Resign** and launch GD.

Includes Windows x64, macOS Intel/Apple Silicon, and iOS/iPadOS arm64. Requires GD 2.2081, Geode 5.11.1+ (5.x), and Attempt Playback 1.5.7.
